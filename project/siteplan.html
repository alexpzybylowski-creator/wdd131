Site Name

I chose the name PC Upgrade Advisor because it clearly describes what the website does. The website helps users understand which computer components they could upgrade.

Site Purpose

The purpose of this website is to help users find better upgrades for their computers. Users will enter their current PC components, such as the CPU, GPU, RAM, and storage. They will also choose what they use their computer for. The website will then recommend better components based on their current setup and their needs.

The website will use JavaScript to compare the user's current components with other available components and display upgrade recommendations.

Scenarios

These are questions that a user might have when visiting the website:

  • Which component should I upgrade first on my current PC?
  • What would be a better GPU for my gaming computer?
  • What upgrades would improve my PC for programming?
